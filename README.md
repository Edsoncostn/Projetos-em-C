## Como executar os projetos em C

Cada projeto possui um arquivo `.c` e instruções específicas em seu README. Para compilar, entre na pasta e utilize um compilador como GCC:

```bash
gcc -std=c11 -Wall -Wextra nome_do_arquivo.c -o programa
./programa
```

No Windows, o executável normalmente terá a extensão `.exe`.

## Sobre a organização
